Clockstwo of them

Session · the mild one

Resets every 5 hours

Stops you mid-day. Wait it out, or drop to ordinary chat, which costs a fraction of Cowork. Countdown is on the usage screen.

Weekly · the awkward one

Fixed day and time

Across all models, refilling only at the slot assigned to your account. Nothing speeds it up — spread big runs out instead of stacking them.

Both live at Settings → Usage, with the next reset time. The docs never state exactly when a session starts — read the countdown rather than trusting a remembered rule.

Context window

Up to 1M tokens on the newest paid plans, 500K or 200K otherwise, with part always reserved for the reply. A chat that starts feeling vague has compressed its own early detail — that is the signal to start fresh.

Leverspick one

Four ways to make a job fit

A
Split the job into smaller runsWhen it died partway through.
B
Start a fresh conversationWhen the chat is long and has drifted. Free, instant, most under-used.
C
Put the document into a ProjectWhen it's a thing you keep returning to. Cached — re-referencing costs almost nothing.
D
Capture the process as a SkillWhen it's a way of doing things you keep re-explaining. Unread until its description matches.
+
Batch related questions into one message

The one that gets confused

C is for a thing. D is for a way of doing things. A policy PDF you quote → Project. The five rules you apply to every deck → Skill.

Blockedwhat now

In order

  1. Which clock stopped you? Session means hours; weekly means plan differently.

  2. Session-blocked and still need something? Ordinary chat costs a fraction of Cowork.

  3. Genuinely can't wait? Usage credits continue at standard API rates within a cap you set — the escape hatch, not the strategy.

  4. Happening often? The job is too big for how you're running it. Go to the four levers.

Before any long run

Check the time left in the current session. Starting a forty-minute job with twenty minutes left is the most avoidable way to lose work.
