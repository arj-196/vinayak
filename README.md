# Vinayak's workspace

Two halves, kept apart on purpose.

| Directory | What it holds | Who it is for |
|---|---|---|
| **[`learning/`](learning/README.md)** | The course: twelve lessons, reference cards, the mission, working notes. Published at **https://arj-196.github.io/vinayak/learning/** | Vinayak, as the learner |
| **[`projects/`](projects/README.md)** | Improvement plans and reasoning for Vinayak's real workflows | Vinayak and Arjun, as colleagues |

Start with the course: **[learning/README.md](learning/README.md)** is its index, and the website
link above opens every lesson as a normal web page.

`projects/` stores *how we think about* a workflow: the diagnosis, the target design, the pilot
plan, the decisions taken. It never stores the workflow's own prompt, source documents, or
figures. Those stay with their owner.

[CLAUDE.md](CLAUDE.md) holds the rules for whoever edits this repository.
