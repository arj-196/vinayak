# Baseline: fluent in chat, zero coding exposure assumed

Established 2026-09-07 from Arjun's brief, **not yet from the learner directly** — treat as
secondhand until the intake artifact returns.

Vinayak gets good results from Claude in chat and does not need prompting taught. Everything
past the chat box is new: Skills, Cowork, Claude Code, agents. Arjun's explicit instruction is
that no coding comfort may be assumed — terminal, file paths, Markdown, YAML and git each need
their own on-ramp built into the lesson that first needs them, never treated as a prerequisite.

**Implications.** The journey is ordered Skills → Reach → Cowork → Code specifically so that
file-and-folder confidence accumulates as a side effect of Stage 1 before the terminal is ever
mentioned in Stage 04. L03 teaches Markdown and YAML by having him read a `SKILL.md` he
authored himself in L01, rather than teaching the syntax cold. L12 spends a whole lesson on the
terminal with no Claude in it at all.

Reading tolerance is low and is a hard design constraint, not a preference: one screen of
reading per lesson, then practice. A lesson that needs more explanation than that is scoped too
big and must be split.
