What a Skill is made of

Everything from L01 and L02, compressed. Come back to this rather than re-reading the lessons.

Shapethe file

A Skill is one plain-text file called SKILL.md, optionally in a folder with extra files beside it. Nothing is compiled and nothing runs — it is a written process.

---
name: client-status-decks
description: Formats weekly client status decks in the
  house structure. Use when the user mentions a client
  deck, a status deck, a weekly update slide, or asks to
  build or restructure a PowerPoint for a client.
---

The fenced block at the top is frontmatterSettings about the file, kept separate from the content. The format is called YAML.
name
Lowercase letters, numbers and hyphens only. Max 64 characters.Cannot contain the words "claude" or "anthropic".
description
The trigger. Max 1,024 characters. Third person.The only part Claude reads before choosing. Gets both halves or it fails.
body
Your actual process, in Markdown. Under 500 lines.Never opened unless the description won.
Formulathe trigger

The description formula

[What it does, third person.] Use when [the words
you would really type], [a synonym], [a synonym],
or [the file type / the thing it touches].

Listing the same request three or four ways is the mechanism, not padding. Include your colleagues' words too, not only yours.

Fails vs fires

✗
Helps with documents — matches nothing anyone types
✗
I can help you format decks — first person
✗
You can use this for decks — second person
✗
What it does, with no "Use when" half at all
✓
Third person, both halves, real phrasings listed
Debuggone silent

Skill isn't firing — in order

  1. Is it switched on? Settings → Customize → Skills.

  2. Does the description have a "Use when" half?

  3. Does it contain the exact words you typed? Not synonyms — the literal words.

  4. Is it third person? No "I" or "you".

  5. Still stuck: paste the description into Claude and ask why it wouldn't trigger for your request.
